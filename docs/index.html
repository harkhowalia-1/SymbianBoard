SymbianBoard

Symbian apps on your iPhone.

The phone's real apps — Calculator, Gallery, Notes, games and anything you install — running in an emulated Nokia, on a home screen that behaves like iOS.

What it does

Built on the EKA2L1 Symbian emulator, with a front end made for the iPhone.

iPhone-style home screen

Pages of real Symbian icons, a dock, folders, long-press actions and jiggle mode.

Or the full Symbian look

Switch to a Symbian^3 Menu with its status bar and Options / Exit softkeys.

The N8's Menu key

The silver key from the N8's body sits under every app. Call keys appear in calling apps.

Install with +

Pick a .sis or .sisx package and it installs onto the phone, icon and all.

Your photos and music

Your newest photos show up in the N8's own Gallery; songs on the iPhone are copied for the Music player.

Shortcuts

Add any Symbian app to the iPhone Home Screen, run it from Shortcuts, or ask Siri.

Not available yet
Firmware is not included. Nokia's firmware is copyrighted, so SymbianBoard ships without it. On first launch choose Install Device → Zip or 7z archive and pick the firmware zip of a phone you own, just as you downloaded it (for example a Nokia N8, RM-596) — or an unzipped folder with its .vpl file.

Install

  1. Install the IPA with AltStore, SideStore or Sideloadly — or add the source above.
  2. For full speed, enable JIT for SymbianBoard with SideStore or StikDebug. Without JIT it still runs, more slowly.
  3. Open SymbianBoard and install your device's firmware from its downloaded .zip.
  4. Tap + to add Symbian apps (.sis / .sisx), then open them from the home screen.
